# greenworld

**GreenWorld Wellness** — a premium, classic, mobile-first health & wellness WooCommerce theme for **Green World Health Solutions** (Kenya).

- `greenworld/` — the parent theme (upload & install this).
- `greenworld-child/` — the child theme (activate this; your customizations live here).

Botanical-green + warm-ivory design system, editorial typography (Fraunces + Inter), health mega-menu, AJAX search, cart drawer, dual **Customer / Distributor** registration, an online **Health Consultation** intake, responsible health communication, Core Web Vitals performance and WCAG 2.1 AA accessibility.

See `greenworld/README.md` for full setup and admin documentation.
